# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/traefik.svg` | Default (brand colour, used as `<img>` fallback) |
| `icon-light.svg` | `svg/traefik-dark.svg` | Dark-coloured logo for light backgrounds |
| `icon-dark.svg` | `svg/traefik-light.svg` | Light-coloured logo for dark backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/traefik.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/traefik-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/traefik-light.svg
